Help & support

Updated 13 November 2026

Start a report

Create a project, add work items, then add photos to each placeholder. Use the arrows or swipe to choose the displayed candidate. Choose two or four photos per page. Groups can be phases, job types, areas or your own names.

Saving

Wait for “Saved on this device” before closing. If saving fails, keep SiteFlow open, free some device storage and choose Retry saving. The latest edits may exist only in memory until retry succeeds.

Back up and transfer

Choose Save backup, then save the .siteflow file to Files or another destination. Check that the file is there. On the other device, choose Restore backup and select it. Restoration creates a separate project. A PDF is a report, not a restorable project backup.

Recover removed work

Use Removed projects in the project list, Removed work items inside a project, or Recover photo below its placeholder. Recovery preserves candidate selections and original ordering. Removed work items are excluded from PDFs but included in backups.

When projects will not open

Use Retry opening. If that fails, Restore from backup opens a verified portable backup in a fresh database while preserving the original data. Do not uninstall SiteFlow while trying to recover work. Contact info@ecologic.nz if you do not have a backup or need help.

PDF checks and limits

Choose a photo in every visible placeholder. Preview checks for missing images and overflowing text before enabling export. Keep headings to 100 characters, descriptions to 600 and photo labels to 48. Reports support up to 50 work items, subject to a 24 MiB prepared-image limit. Selected source images above 60 megapixels must be replaced with smaller copies for the report. Original imported files are not resized by PDF export. Long reports may need to be split into separate projects.

Camera and photos

If camera access was denied, enable it in device settings or use Import. Limited photo-library access is supported through the system picker. Check that imported photographs have the orientation and quality you expect before exporting.

Get help

Email info@ecologic.nz with your device model, operating system version, SiteFlow version, what you were doing and the exact error. Avoid sending personal/customer photos or a full backup unless we agree they are necessary. There is no need to send passwords or verification codes.
